# 使用指南

QuickLook Fast 是本地预览原型；文件格式、字体和内容会影响预览结果。

## 操作与设置

| 操作 | 作用 |
| --- | --- |
| Space / Esc | 在已接入的文件管理器打开或收起预览；设置、信息面板打开时 Esc 先关闭面板。 |
| 方向键 | 启用设置时尝试切换发起预览的文件管理器选区；文件夹内部操作不会改变外部选区。 |
| 图钉 | 固定并置顶当前预览，可继续打开其他文件；取消固定后恢复普通窗口层级。 |
| 图片滚轮 | 在图片表面小步缩放；普通滚轮一格约 5%。 |
| 信息按钮 | 查看文件属性；支持的照片尝试显示 EXIF。 |
| 托盘退出 | 完全退出应用，普通关闭只隐藏活动窗口。 |

设置分为常规、阅读与文本、文件夹、系统集成和关于。默认启用方向键、媒体自动播放、行号、Markdown 目录、文件夹内预览和图片缩略图；普通预览只显示到前方，不永久置顶，图钉负责固定并置顶。Finder 实验快捷键默认关闭。开机自启由用户选择。Windows 不显示任务栏按钮；macOS 隐藏 Dock 并显示菜单栏图标的实现尚需实机验收。

## 文件夹

目录按页和层级读取。点击左侧文件可在右侧查看；在“设置 → 文件夹”关闭文件预览后，目录占用完整宽度。可独立关闭缩略图。PNG、JPEG、GIF、WebP、BMP、AVIF 图片在可见时加载，压缩文件超过 12 MiB 时使用类型图标；Office、PDF、视频等暂时显示类型图标，不生成内容缩略图。浏览器仍可能解码整张图片。

单页最多 200 项，单目录最多 2000 项，最多登记 5000 个目录、20000 个文件和 32 层；链接不展开。数量是已读取的根目录项数，不是递归统计。目录总大小尚未计算。文件变化时分页结果可能改变。

文件夹内选中的 PDF、音视频和常见图片使用本地 URL；普通文件使用对应渲染器。超过 16 MiB 的常见文本只显示开头 1 MiB，未提供末尾/完整加载按钮。超过 128 MiB 的未加密 OOXML 先展示结构；加密 OOXML 和 ZIP/RAR 沿用密码与大小限制。复杂文档在文件夹内的还原度和性能仍需真实桌面测试。

## 内容和限制

| 内容 | 支持与边界 |
| --- | --- |
| 图片 | Chromium 处理 PNG/JPEG/GIF/WebP/BMP/AVIF，其他格式由 Flyfish 尝试。浏览器仍会解码像素；EXIF 只检查开头最多 512 KiB。 |
| PDF | Flyfish/PDF.js 尝试范围读取并限制预取；加密 PDF 密码尚未统一接入。 |
| 音频 | 浏览器自动播放并支持拖动波形定位；不超过 6 MiB 且不超过 90 秒时尝试解码真实波形，其余显示标注的波形示意，播放仍走流式媒体。具体编码支持取决于 Chromium。 |
| Office | DOCX/XLSX/PPTX 由 Flyfish 渲染；常见密码加密的输入与输出各限 64 MiB，解密及完整渲染仍可能整体占内存。旧版 Office、IRM 和证书加密不保证。 |
| ZIP/RAR | 按需列目录并读选中条目，单条目压缩及解压后各限 64 MiB，最多 20000 项、64 层；ZIP 中央目录最多 16 MiB。单卷 ZIP 的 STORE/DEFLATE、AES/ZipCrypto 和常见 RAR 密码已测试；分卷及部分加密组合不支持。 |
| 大文本 | 超过 16 MiB 默认读取 1 MiB 开头；顶层预览可切换末尾，16–64 MiB 可选择完整加载。5 GiB TXT 不会默认整读。片段行号从片段开始。 |
| Markdown/字幕 | Markdown 左侧目录可关闭并跟随阅读；SRT/VTT/ASS/LRC 等可作为文本查看，不是时间轴播放器。 |
| 未知格式 | 最多先检查 8 KiB，像文本则按文本查看，否则显示信息和最多 64 字节文件头；判断是启发式的。 |
| 快捷方式 | Windows 指向文件夹的 `.lnk` 可预览其目标文件夹，其他快捷方式显示可读取的信息；文件夹树内链接不展开。 |

密码只用于当前预览，不写入设置或日志；运行时和操作系统不保证内存立即清零。文档工具栏“匹配 0/0”是搜索匹配数，不是页码。

## 平台与故障排查

Windows 支持 Explorer、桌面及 Directory Opus 的入口；DOpus 双栏和快速连续操作需要在实际桌面核验。若 Space 不响应，先检查是否与 QuickLook、Peek 或 DOpus 自身快捷键冲突，再查看“设置 → 系统集成”的状态。备用路径参数配置见 [DOpus 说明](platforms.md)。

macOS 26+ Apple Silicon 的 Finder/桌面只提供需启用的 `⌘ Shift Space` 实验入口，裸 Space 尚未接管系统 Quick Look。Linux GNOME 使用预览 D-Bus，KDE Dolphin/Nemo 使用菜单操作；Wayland、X11 和各文件管理器版本需分别验证。[平台说明](platforms.md)。
