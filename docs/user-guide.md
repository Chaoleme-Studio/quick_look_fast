# 使用指南

QuickLook Fast 是本地文件预览工具；文件格式、字体和内容会影响预览结果。

## 操作与设置

| 操作 | 作用 |
| --- | --- |
| Space / Esc | 在已接入的文件管理器打开或收起预览。默认即使按钮或设置开关有焦点，Space 也优先收起预览，可在“设置 → 常规”关闭此行为。设置或信息面板打开时，Esc 先关闭面板。 |
| 方向键 | 在已支持选区跟随的文件管理器切换文件，macOS 使用 ↑ 和 ↓；文件夹内部操作不会改变外部选区。Dolphin 目前不能在预览窗口内跟随切换。 |
| 图钉 | 固定并置顶当前预览，可继续打开其他文件；取消固定后恢复普通窗口层级。 |
| 图片滚轮 | 在图片表面小步缩放；普通滚轮一格约 5%。 |
| 图片抓手 | 放大到超出窗口后，按住鼠标左键拖动图片。 |
| 使用默认应用打开 | 使用系统默认应用打开当前预览的文件；预览文件夹时打开该文件夹。 |
| 选择文件预览 | 点击顶部文件夹图标，或按 Ctrl+O（macOS 为 ⌘+O）选择另一个文件。 |
| 信息按钮 | 查看文件属性、图像尺寸和照片 EXIF。 |
| Word / PPT 页码 | 标题栏右侧、信息按钮旁显示当前页和总页数；点击两侧按钮翻页，输入页码并按 Enter 跳转。滚动时页码随当前位置更新。文件夹和压缩包内的文档显示在各自的预览标题旁。 |
| Word 文档导航 | 在左侧查看按标题样式生成的章节，点击可跳转；顶部目录图标可展开或收起。文件夹和压缩包中的 Word 也可在预览标题处展开。没有标题样式的文档会显示提示。 |
| 托盘退出 | 完全退出应用，普通关闭只隐藏活动窗口。 |

设置分为常规、阅读与文本、文件夹、系统集成和关于。默认启用方向键（适用于已接入的文件管理器）、媒体自动播放、文档页码控件、行号、Markdown 目录、文件夹内预览和图片缩略图。可在“阅读与文本”中即时调整页码控件。图钉可固定并置顶预览。开机自启由用户选择。macOS 可在“系统集成”独立调整 Dock 和菜单栏图标。

HTML 默认打开网页并在隔离框架中运行本地脚本，可在“设置 → 阅读与文本 → HTML 网页运行脚本”关闭；切换时当前网页会重新加载。网页工具栏可切换源码，源码最多读取开头 1 MiB。网页、文件夹中的 HTML 和压缩包中的 HTML 使用相同设置。HTML 超过 64 MiB 时需主动点击加载完整网页，避免选中极大文件就自动占用大量内存。

本地网页通过隔离框架运行，不能使用桌面程序接口；HTTP(S)/WebSocket 外联、弹窗、表单提交、顶层跳转和本地文件访问受限，不能把它视为完整的浏览器网络或进程隔离。`localStorage` 等持久存储也可能不可用，相邻的 CSS/图片/脚本文件暂不自动加载。包含远程依赖、保存状态或特殊权限的网页可能不能完整工作。大型网页按浏览器流式读取，浏览器解析 HTML、运行脚本和解码内嵌资源仍会消耗内存。

## 文件夹

目录按页和层级读取。点击左侧文件可在右侧查看；点预览标题左边的目录按钮可收起或展开侧栏，当前内容保持打开，ZIP/RAR 预览也可使用该按钮。在“设置 → 文件夹”关闭文件预览后，目录占用完整宽度。可独立关闭缩略图。PNG、JPEG、GIF、WebP、BMP、AVIF 图片在可见时加载，压缩文件超过 12 MiB 时使用类型图标；Office、PDF、视频等暂时显示类型图标，不生成内容缩略图。浏览器仍可能解码整张图片。

“设置 → 文件夹 → 隐藏 macOS 系统文件”默认开启，在文件夹和 ZIP/RAR 预览中隐藏 `.DS_Store` 文件及 `__MACOSX` 文件夹。关闭开关可重新显示；此设置只影响预览列表，不会删除或修改文件。

单页最多 200 项，单目录最多 2000 项，最多登记 5000 个目录、20000 个文件和 32 层；链接不展开。数量是已读取的根目录项数，不是递归统计。目录总大小尚未计算。文件变化时分页结果可能改变。

文件夹内选中的 PDF、音视频和常见图片使用本地 URL；普通文件使用对应渲染器。超过 16 MiB 的常见文本只显示开头 1 MiB，未提供末尾/完整加载按钮。超过 128 MiB 的未加密 OOXML 先展示结构；加密 OOXML 和 ZIP/RAR 沿用密码与大小限制。复杂文档在文件夹内的还原度和性能仍需真实桌面测试。

## 内容和限制

| 内容 | 支持与边界 |
| --- | --- |
| 图片 | Chromium 处理 PNG/JPEG/GIF/WebP/BMP/AVIF，其他格式由 Flyfish 尝试。独立图片预览在标题栏显示已识别的尺寸，文件夹和压缩包中的图片在内容区显示尺寸。TIFF 采用首张已解码页面，SVG 也可显示矢量视框。 |
| PDF | Flyfish/PDF.js 尝试范围读取并限制预取；加密 PDF 密码尚未统一接入。 |
| 音频 | 浏览器自动播放并支持拖动波形定位；不超过 6 MiB 且不超过 90 秒时尝试解码真实波形，其余显示标注的波形示意，播放仍走流式媒体。具体编码支持取决于 Chromium。 |
| Office | DOCX/XLSX/PPTX 由 Flyfish 渲染；常见密码加密的输入与输出各限 64 MiB，解密及完整渲染仍可能整体占内存。旧版 Office、IRM 和证书加密不保证。 |
| ZIP/RAR | 按需列目录并读选中条目，单条目压缩及解压后各限 64 MiB，最多 20000 项，归档内文件路径最多 64 层；ZIP 中央目录最多 16 MiB。ZIP 内的 `.zip` 可继续浏览，从外层压缩包向内最多嵌套 4 层；RAR 混合嵌套仍需验证。单卷 ZIP 的 STORE/DEFLATE、AES/ZipCrypto 和常见 RAR 密码已测试；分卷及部分加密组合不支持。 |
| 大文本 | 超过 16 MiB 默认读取 1 MiB 开头；顶层预览可切换末尾，16–64 MiB 可选择完整加载。5 GiB TXT 不会默认整读。片段行号从片段开始。 |
| Markdown/字幕 | Markdown 左侧目录可关闭并跟随阅读。相对图片支持文档所在目录及其子目录中的 PNG、JPEG、GIF、WebP、BMP、AVIF，单张最多 12 MiB、每次最多 128 张；不读取目录外路径、符号链接到目录外的文件或网络图片。SRT/VTT/ASS/LRC 等可作为文本查看，不是时间轴播放器。 |
| 未知格式 | 最多先检查 8 KiB，像文本则按文本查看，否则显示信息和最多 64 字节文件头；判断是启发式的。 |
| 快捷方式 | Windows 指向文件夹的 `.lnk` 可预览其目标文件夹，其他快捷方式显示可读取的信息；文件夹树内链接不展开。 |

DOCX 及相关 OpenXML Word 文档按当前预览排版分页，字体、图片和复杂布局可能使页数与 Word 不一致；旧版 DOC/PPT 暂无统一页码控件。PDF 使用其自带的页码工具栏。文档工具栏“匹配 0/0”是搜索匹配数，不是页码。所有已接入的扩展名见[格式清单](formats.md)。

密码只用于当前预览，不写入设置或日志；运行时和操作系统不保证内存立即清零。

点击图片右上角的信息按钮，可查看原图记录的相机、镜头、拍摄时间、感光度、光圈、曝光时间和焦距。JPEG、PNG、WebP、TIFF 和 HEIF/AVIF 会尝试读取 EXIF。文件没有可用字段、元数据超出读取范围或解析失败时，面板会显示对应状态，已识别的图片宽高仍会显示。截图和经过聊天软件转存的照片可能已丢失 EXIF。

## 更新应用

打开“设置 → 关于”，点击“检查更新”查询 GitHub 最新正式 Release；如有新版，点击“手动下载”并选择自己的系统和架构。下载和替换由用户自己完成，建议先退出正在运行的程序。此功能不自动下载、不自动覆盖，不监听测试版或草稿；检查时需要联网，可能受 GitHub 请求限额影响。更新检查通过独立的 Chromium 网络会话使用系统代理，向 GitHub 发出 HTTPS 请求，不上传预览文件。

遇到卡顿或渲染进程退出时，可在“设置 → 关于 → 运行诊断”打开本地日志目录。`diagnostics.log` 只记录时间、进程状态、错误类别和退出码，不记录文件名或文件内容；日志大小受限，不会上传。系统原生崩溃弹窗或进程来不及写日志时，仍可能没有对应记录。

## 本地崩溃诊断

Windows 的 `0x80000003` 可能由多个不同的原生故障产生，仅靠弹窗无法判断原因。当前版本恢复了隐藏窗口的后台节流，并修正了 Windows 崩溃报告辅助文件名；这两项改动不能证明已经解决所有异常。

需要继续定位时，可选择启用本地转储：

1. 先从托盘完全退出 QuickLook Fast，避免单实例把参数转发给旧进程。
2. 在所使用的便携版本目录打开 PowerShell，运行 `& '.\QuickLook Fast.exe' --diagnostics`。
3. 正常预览并等待问题复现。若 Electron 能捕获到异常，转储会保存在 `%APPDATA%\QuickLook Fast\crash-dumps\`；状态日志位于 `%APPDATA%\QuickLook Fast\logs\diagnostics.log`。
4. 完成排查后退出应用，正常启动即可关闭本次诊断模式。历史转储可以由用户自行删除。

转储可能包含进程内存中的文件名、路径或文档片段，只保存在本机，不自动上传；分享前请确认内容。某些原生故障可能无法捕获，因此没有转储也不能证明没有崩溃。

## 平台与故障排查

Windows 支持 Explorer、桌面及 Directory Opus 的入口；DOpus 双栏和快速连续操作需要在实际桌面核验。若 Space 不响应，先检查是否与 QuickLook、Peek 或 DOpus 自身快捷键冲突，再查看“设置 → 系统集成”的状态。备用路径参数配置见 [DOpus 说明](platforms.md)。

macOS 新安装默认选择 **QuickLook Fast · Space**。在系统设置授权辅助功能后，Finder 和桌面的空格预览会自动启用。可在“设置 → 系统集成”切换为 **macOS 快速查看** 或 **QuickLook Fast · ⌘⇧Space**。两个应用图标都隐藏后，从 Spotlight 搜索 QuickLook Fast 可重新打开设置。

Linux 预览窗口按屏幕可用区域设置初始大小；可以通过系统标题栏移动，从窗口边缘或角落调整大小。GNOME 使用预览 D-Bus；KDE Dolphin/Nemo 使用菜单操作。Dolphin 的 Space 需要在安装菜单后自行绑定；它原有的 Space 选择模式会与预览冲突。1.0.0 提供可选的实验性 Plasma 桌面接入，0.3.0 发布包尚不包含。[Linux 安装、快捷键、恢复与卸载](platforms.md#linux)。
