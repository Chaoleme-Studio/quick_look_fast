# 历史需求与核验清单

本清单整理本会话中用户提出的目标和问题，供新会话逐项核验。**“代码／模拟”不等于真实桌面通过**；没有截图或平台实测证据的项目保持待核验。用户提供的工作文档和图片原件不写入此清单，工作文档不随仓库分发。

V15 补齐了独立图片预览的尺寸和文件信息，文件夹和压缩包里的图片也显示已识别的宽高。EXIF 按原图字段显示，PNG、WebP 可跳过图像数据定位 EXIF。`patch/`、`scripts/` 和平台源码归位，根 README 统一作为文档入口。

仍待确认或尚未实现的主要项目包括长时间闲置后出现的 Windows `0x80000003`、DOpus 双栏和快捷键的用户环境复测、macOS Finder 裸 Space、Linux 实际桌面集成、Office 原文件逐页还原，以及 100 ms 响应目标和进程树内存实测。目录递归体积、专业文档缩略图、部分加密格式和压缩包组合仍有限制，见下表。

| 状态 | 含义 |
| --- | --- |
| 代码／模拟 | 有实现及自动测试或结构检查；仍可能存在真实桌面差异。 |
| 待桌面 | 有实现或修复，但用户报告的问题需要在对应系统和真实文件中复现验证。 |
| 未实现 | 目标尚未交付或只实现了替代入口。 |

## 新会话建议验收顺序

1. 在正常 Windows 桌面退出旧版托盘，运行最新构建；验证 Explorer、桌面和 DOpus 双栏的连续空格、快速点击、方向键、图钉和焦点。
2. 用无隐私样本测试文件夹缩略图与右侧预览开关、加密文档、ZIP 内 Word 滚动和大 TXT。
3. 用用户本机保留的 PPT 分别与 PowerPoint 对照颜色、箭头、竖排、首页和第 31 页图表。
4. 在正常桌面运行 `pnpm run screenshots` 并检查生成的合成样本截图；脚本会更新 README 截图区域，不读取真实磁盘、工作路径或私密文档。
5. 在 GitHub 和各目标系统验证 Release 工作流、安装、权限与桌面快捷键，记录可重复的延迟和内存数据。
